# 多面体 · 会说很多种话的聊天机器人

一个 Python 写的网页版聊天机器人。同一个问题，可以让六种性格的人来回答，回复是**流式输出**（边生成边显示）。

## 跑起来

```bash
pip install -r requirements.txt
python app.py
```

Windows 上直接双击 `run.bat` 也行。启动后打开终端里提示的地址（默认 <http://127.0.0.1:5000>）。

API Key 放在项目根目录的 `.env` 里，仓库里已经填好了你给的那个：

```
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
PORT=5000
```

`.env` 已经被 `.gitignore` 排除，不会被提交。

## 怎么用

- **换性格**：左边点一下就行，整个界面会跟着换主色。
- **每个性格各聊各的**：切过去接着上次说，互不串味。想重开就点右上角「新对话」。
- **自定义性格**：点左下角「＋ 自定义性格」，填名字、口头禅、他是谁、怎么说话，再挑个主色。自定义的性格存在浏览器本地；鼠标移到卡片上，右上角会出现删除按钮。
- **灵动度**：滑杆就是 temperature，0 一本正经，1.5 天马行空，每个性格单独记。
- **模型**：`deepseek-chat` 快而稳；`deepseek-reasoner` 会先想再答，思考过程收在一个可展开的「思考过程」里。
- **停止**：生成中点「停止」就断掉，已经写出来的字会留着，并标上「（已停止）」。

## 内置的六种性格

| 性格 | 一句话 | 主色 |
| --- | --- | --- |
| 御姐 | 别急，把话说明白。 | 鎏金 |
| 萌妹 | 诶？你又来啦～ | 桃粉 |
| 古灵精怪 | 先猜一个大胆的答案。 | 青绿 |
| 温柔知心 | 慢慢说，我在。 | 雾蓝 |
| 高冷学霸 | 结论先讲，理由跟上。 | 银蓝 |
| 毒舌损友 | 行，我直说了。 | 焰橙 |

性格写法都在 `personas.py` 里，想改口吻直接编辑 `prompt`，想加一个就往 `PERSONAS` 后面追加一条。

## 文件结构

```
app.py                   Flask 服务：页面、/api/chat 流式转发、错误翻译
personas.py              性格定义 + 系统提示词拼装
templates/index.html     页面骨架
static/css/style.css     样式（每个性格一套主色）
static/js/app.js         前端逻辑：切换性格、流式渲染、Markdown、本地存档
.env                     API Key（不进 git）
```

## 出问题怎么查

| 现象 | 原因和处理 |
| --- | --- |
| 页面上写「没有找到 API Key」 | `.env` 没填或没重启服务。 |
| 回复里出现「API Key 无效或已失效」 | Key 被禁用或写错了，去 platform.deepseek.com 换一个。 |
| 「账户余额不足」 | DeepSeek 账户要充值。 |
| 「连不上 DeepSeek 接口」 | 本机网络或代理的问题，换个网络试试。 |
| 端口被占用 | 会自动往后找端口，看终端打印出来的地址。 |

## 一点实现说明

后端不落地任何对话，只做两件事：把性格拼成 system 提示词，把 DeepSeek 的 SSE 原样转成给浏览器的 SSE。对话历史存在浏览器 localStorage 里，随时刷新都在。

只有 `Flask` 和 `requests` 两个依赖，前端不引任何 CDN，断网也能把界面打开。
